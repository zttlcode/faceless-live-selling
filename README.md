# 不出镜直播话术 Skill

以《主播从0到1必修课》的完整课堂笔记为核心，结合实际话术示例中提炼的方法，为不出镜带货生成**一份完整、能直接念的口语直播稿**。

生产顺序：课程框架与节奏 → 商品理解与必要核实 → 选择有关技巧充实内容 → 全文口语化。

支持单品、多商品、平播与憋单。开播前生成，不承担实时接话或直播监控。没有附稿、备用话术库、训练版或逐句语气提示。

## 需要提供什么

| 输入 | 怎么填 |
| --- | --- |
| 商品资料 | 名称、链接、特点、规格、实际售价、真实优惠、发货售后；多商品依次提供 |
| 计划时长 | 整场时长，或本次指定某款的几分钟 |
| 人数档位 | 第一档0—15人，第二档16—80人，第三档81人及以上；直接填人数也行 |
| 售卖倾向 | 每款以低价福利还是价值为主；可以全场统一，也可每款不同 |

人数按第五课的三档服务逻辑选择。原课边界是约数，本工具把15人归第一档、80人归第二档，以便输入；它决定备稿节奏，不是要求实时读取人数。

**福利或价值由你选择，不按绝对售价自动分类。** 售价150元，若重点是相对真实可比商品的价格优势，也可以做福利款；售价低也能侧重材料、用途或审美价值。

选择福利时说明实际优惠、价格参照与依据。例如“我卖150元，别人卖3000元”，还需说明比较的是什么商品、规格和条件。技能会保留你的福利倾向，核实后使用有关参照，不自行写成同款同料或全网最低，也不因150元而改成价值款。

这四项缺失时，技能会集中补问。已经确认的资料可以沿用；不要求你自己先提炼痛点和核心卖点。[输入模板](skills/faceless-live-selling/assets/session-input.md)可按需要使用。

## 最简单的用法

```text
$faceless-live-selling

请准备一场30分钟的不出镜直播，只生成一份完整口语稿。
人数档位：第一档，预计10人左右。
模式：平播，链接一直可以买。
说话风格：自然、亲切、明确，不要作文腔。

商品1：
- 名称、链接编号：填写
- 材质、规格、特点：填写或粘贴详情页
- 实际售价：填写
- 售卖倾向：价值为主
- 真实优惠、发货和售后：填写，未确认的请注明

商品2：
- 名称、链接编号：填写
- 材质、规格、特点：填写
- 实际售价：填写
- 售卖倾向：低价福利为主
- 价格优势或真实优惠及依据：填写
- 发货和售后：填写

请安排商品顺序与循环，写完整场正文。
关键资料不足时先集中问我，不要附稿或逐句语气提示。
```

写短稿也使用同样四项，例如：

```text
请用已确认的凤眼菩提资料写3分钟话术。
人数档位：第二档。
售卖倾向：价值为主。
模式：平播。
只要一份直接照念的稿子。
```

选择憋单时，额外说明谁控制购买入口、怎样限制购买、何时或按什么规则开放。稿中会简短标出实际操作节点，由本人或中控确认开放后才读可购买台词；技能不会替你操作。

## 不同输入怎样影响稿子

- **第一档**：先建立兴趣，再用具体偏好帮助选择，一个问题接一个有关卖点，及时引导下单。没有人回复时也有正文继续，不虚构反馈。
- **第二档**：一轮讲清留人、塑品、报价和促单后再转款，避免讲解反复倒回去。
- **第三档**：平播按短塑品、勤促单组织不同购买角度；憋单区分开放前积累需求与开放后促单。
- **福利为主**：重点是可信的价格优势、力度和理由，配合基础品质、用途与购买条件。
- **价值为主**：重点是需求、核心特点带来的好处、价值依据，再承接价格与购买。

人数档位、定位倾向和售卖模式是不同维度，不机械绑定。多商品可以用福利款拉新、价值款深入讲解，具体按输入与真实商品关系安排。

## 会得到什么

一份稿件包含本场需要的开场、商品轮次、报价、促单、转款与收尾。价格顾虑、信任、拉新等内容按需要放入正常流程或后续轮次，不另生成附稿。短稿直接给连贯正文，长稿可按商品与时间分段，必要时保存为一个Markdown文件。

默认写足计划时长的正文，不只列提纲；你明确接受按轮复用时，再以已写完整的段落和明确顺序组织循环。实际播速与停顿会影响用时，开播前试读校准。

口语化在内容和框架之后完成：讲清产品、好处、理由与动作，减少书面词、含糊缓冲和写作旁白。场景、审美和情感按商品需要取用，不强制生活故事，不堆拿起放下、低头看等动作描写，也不把商品介绍写成散文。

## 安装

技能名：`faceless-live-selling`。将仓库中的整个 `skills/faceless-live-selling` 文件夹复制到当前环境识别的技能目录，保留内部结构；同一个环境避免重复安装。

也可以把下面这段发给支持 skill-installer 的助手：

```text
请用 skill-installer 安装这个技能：
https://github.com/zttlcode/faceless-live-selling/tree/main/skills/faceless-live-selling
```

安装后使用 `$faceless-live-selling` 调用。当前技能以说明和参考文件组成，不依赖实时数据接口；其他支持SKILL.md的客户端尚未逐一验证。

```text
faceless-live-selling/
├─ README.md
└─ skills/faceless-live-selling/
   ├─ SKILL.md
   ├─ agents/openai.yaml
   ├─ assets/session-input.md
   └─ references/
      ├─ 主播从0到1必修课_完整课堂笔记.md
      ├─ course-method.md
      ├─ prepare.md
      └─ speech-principles.md
```

[完整课堂笔记](skills/faceless-live-selling/references/主播从0到1必修课_完整课堂笔记.md)完整保留六集课程，是结构与节奏的核心依据；先通过[课程提要](skills/faceless-live-selling/references/course-method.md)定位，再按当前任务读取原笔记有关小节，不每次加载全文。

[备稿流程](skills/faceless-live-selling/references/prepare.md)说明如何由输入生成整场稿；[实际话术的方法](skills/faceless-live-selling/references/speech-principles.md)保留用户确认的十份材料、42条方法来源，并补充两份10月22日材料中的有用思路。它们加强商品理解、具象化、共情、信任、价格回应与促单，不照抄案例、不移植事实，也不替代课程框架。

[SKILL.md](skills/faceless-live-selling/SKILL.md)定义入口与读取顺序。事实、价格、比较、经历和售后都须有依据；未知关键信息集中确认，不因追求感染力编造内容。不出镜、不提供逐句语气提示、不实时监控的范围保持一致。
