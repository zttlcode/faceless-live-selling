# 本场直播输入

不必分析专业卖点，粘贴已有商品资料即可。请先提供下面四项，不知道的明确写不清楚，由技能集中补问。

## 必要输入

- 商品资料：见下方，可一件或多件。
- 计划时长：整场多少分钟，或本次只写某款的多少分钟。
- 人数档位：第一档0—15人／第二档16—80人／第三档81人及以上；也可以直接填人数。
- 售卖倾向：低价福利为主／价值为主。多商品可给全场统一倾向，或每款分别填写。

福利、价值是希望话术侧重什么，不按售价绝对值自动分类。选择福利时，请说明真实优惠或比较依据，例如和什么商品、什么规格、什么成交条件相比便宜；“我150元、别人3000元”也要说明参照，不能只凭两个价格认定同款同料。

## 本场补充

- 模式：平播／憋单（不填默认平播）。
- 平台、受众与说话习惯：知道再填，默认自然亲切、直接口语。
- 选择憋单时：谁能控制购买入口、何时或按什么规则开放；真实活动数量或截止条件有再填。

## 每款商品

- 名称、实际链接编号：
- 材质、规格、颜色、用途与已知特点：
- 实际售价及各选项价格：
- 本款售卖倾向（与全场相同可不重复）：
- 真实优惠、价格参照及其依据（没有就写无）：
- 已确认的发货与售后：
- 详情页、图片、真实评价、亲测或报告（有再提供）：
- 主要顾虑、希望保留的内容（知道再填）：

资料确认后，只生成一份完整直播稿。以课程安排结构和节奏，实际案例技巧按需融入，最后用能直接说出口的口语完成。不要附稿、备用话术库或逐句语气提示，也不要把正文写成散文。
