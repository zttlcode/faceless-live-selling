# 课程方法提要

依据：[完整课堂笔记](主播从0到1必修课_完整课堂笔记.md)。以下用于定位方法，不代替本次有关的原笔记小节。用户的商品、人数档位和售卖倾向决定如何应用；案例中的价格、身份、评价和效果不能直接移植。

## 1. 一轮卖货要有成交推进

整场包括开场、单品卖货、转款与收尾。单品主线是定位 → 留人 → 塑品 → 报价与上车 → 促单 → 转款或下一轮。留人解决为什么听，塑品解决为什么想买和为什么值，报价说明成交条件，促单补障碍并给购买动作。

## 2. 用户选择福利或价值重心

第三课的定位决定留人与塑品深度。本工具按用户输入确定侧重，不按售价绝对值分类。150元相对真实可比的3000元也可以做福利款；低价产品也可以侧重价值。福利和价值能相互支持，但本场主次要清楚。

福利留人主要讲真实力度与理由；价值留人可从需求、痛点、向往或有用判断切入。没有依据不宣称同款、同料、全网最低，不编活动背景；比较条件不清先集中核实，不擅改用户的主推倾向。

## 3. 卖点要变成顾客的好处

核心卖点是主要购买理由，课程“80%的用户”是抓重点的教学说法。讲主要特点、相关辅助点、使用好处和价值依据；陌生术语要帮助理解，不能只罗列名字。品牌、来源、工艺等参照须有依据，不能为显贵强贴标签。

场景、情感与审美是可用内容，不是所有商品必写的故事。它们说明用途、体验或有关意义，不能代替产品价值和成交推进。

## 4. 三档人数的节奏

第五课按约15人以内、约15至80人、80人以上粗分。本工具为便于选择，使用0—15人、16—80人、81人及以上，分别对应：

| 档位 | 核心方法 | 备稿时如何体现 |
| --- | --- | --- |
| 第一档 | 留人 → 点人 → 卖货 → 下单 → 连单 | 问容易回答的具体偏好，接一个有关卖点并继续；有兴趣后再推选择，单品不造多选项，连单要有真实理由 |
| 第二档 | 完整讲款，当前轮不被反复打断 | 留人、塑品、报价、促单完成后转款；塑品向前推进，后续轮补内容 |
| 第三档 | 区分平播与憋单 | 平播短塑品勤促单，多轮换角度；憋单先积累需求，实际开放后集中促单 |

输入的是这次备稿预计面对的档位，不是要求系统盯实时数据。低在线的问题后也有默认正文，不假装观众回复。中在线不额外生成点菜卡，高在线不自动替用户关开购买。

## 5. 报价七步按事实取用

课程集中报价的七步是降价、给理由、提要求、明确主推、讲保障、讲限量及原因、给惊喜。它们服务于真实成交条件，不是要求每次凑齐：没有真实参照、活动、库存数量或赠品时省去有关主张。

价格、实际优惠、规格选择和购买动作清楚。平播一直可买，不伪装还没开放；憋单由用户实际开放并确认后再读可买部分。

## 6. 三层促单按障碍安排

意向强的，补真实福利、有关好评或保障与动作；对产品信心不足的，补核心卖点、场景或依据；新来或需求不明的，补可信信息与有关需求。各层内容写进本场相应段落或轮次，不另做附稿，也不强制每层等长。

第四课还讨论约100人以上、促单时掉人的中途关价后再塑品方案，这是特定处理，不与第五课三档人数机械合并，不自动加入正常稿件。没有实际库存信息不说售罄、踢单或最后几件。

## 7. 平播与憋单的轮次

平播可用三个不同维度各完成种草 → 卖点 → 有关顾虑 → 促单，每轮及时给购买理由，不把同一篇长介绍连读三遍。轮数按内容和时长取舍，短稿不强凑。

憋单上车前讲需求、塑品、互动、场景与报价，实际上车后讲真实福利与购买条件。不是只等不开，也不是仅靠口头说不能买。人数档位和售卖模式分别确认。

## 8. 播感落实到口语稿

第六课强调说人话、有重点、敢停顿与投入表达。不出镜稿用词、句子和标点完成自然讲解，不输出逐句语气或表演指令。明确事实直接讲，有关限制在相应节点简洁说清，推荐有判断，购买有动作。

补充案例技巧见 [实际话术的方法](speech-principles.md)，用于改善角度与表达，不替代课程结构，不因追求感染力把主稿改成散文。
